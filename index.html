Scarlet IPA Installer

Generate an iOS OTA installation link for an already-signed IPA hosted at a public HTTPS URL.

Important: GitHub Pages is static hosting, so this page cannot permanently upload an IPA from the browser. Your IPA must already be hosted at a public HTTPS URL. The generated manifest below is a preview; for a working OTA link, save the manifest as manifest.plist in this repository and replace its values with your IPA details.
