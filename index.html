Firebase setup notes

Anonymous Authentication must be enabled. Storage Rules must allow the authenticated uploader to write and the installed device to read the IPA/manifest URLs.

The uploader uses 8 MiB resumable chunks, retries failed chunks, and supports pause/resume/cancel.

The IPA must already be properly signed. This uploader does not sign or modify the IPA.
