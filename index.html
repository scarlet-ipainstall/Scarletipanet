Firebase setup notes

Anonymous Authentication must be enabled in Firebase Authentication. Storage Rules must allow the authenticated upload path used by this page.

The uploader uses Firebase's resumable upload API, so large files can report progress and be paused, resumed, or canceled.

The IPA must already be properly signed. This uploader does not sign or modify the IPA.
